## What it does

`main.ts` (Node 22) writes a single status page line — at most 160 characters — to `/output/entry.txt`: the message an AI agent would publish while every server is down. Plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know. No cause invented, no ETA guessed.

## Run

```sh
node main.ts
cat /output/entry.txt
```
